# 🌍 ReiseApp

En moderne reiseapp som hjelper brukere med å organisere og lagre sine reiser basert på ønskeliste og land som er besøkt tidligere. 

Ta en titt på appen med egen lenke i om-seksjonen. 

---

# ✨ Funksjoner

* 📍 Utforsk populære steder og aktiviteter
* ❤️ Lagre favoritter
* 🌤️ Værinformasjon for destinasjoner
* 📱 Responsivt design for mobil og desktop
  
---
# 🛠️ Teknologier

Prosjektet er bygget med:

* Frontend: React / Next.js
* Styling: Tailwind CSS
* Backend: Node.js / Express
* Database: Prisma Studio
* API: Weather API
